# flux-mcp

MCP-server (Model Context Protocol) voor **Flux**: stelt de Flux-catalogus en
bijhorende resources beschikbaar aan LLM-agents en tooling via MCP.

## Structuur

| Folder        | Inhoud                                               |
|---------------|------------------------------------------------------|
| `server/`     | de MCP-server zelf                                   |
| `catalog/`    | de geversioneerde 'catalogus' die de server ontsluit |
| `resources/`  | scripts enzo                                         |
