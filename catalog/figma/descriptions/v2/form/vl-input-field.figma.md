# vl-input-field

## Figma

Tekstveld voor één regel invoer, van het type text of number. Voor een datum, een bestand, een aanvinkvak of keuzerondjes bestaat een eigen component: vl-datepicker, vl-upload, vl-checkbox, vl-radio-group.

• Elk veld heeft een zichtbaar label (vl-form-label, in code gekoppeld via for). Een placeholder is geen label: gebruik hem enkel voor een voorbeeldwaarde.
• Foutmeldingen staan onder het veld (vl-form-message). Maak ze specifiek en geef de oplossing: "Vul een geldig e-mailadres in. Bijvoorbeeld: omgeving@vlaanderen.be".
• Staat er visuele context bij het veld, zoals een eenheid ("m"), dan maakt describedby die in code ook hoorbaar.
