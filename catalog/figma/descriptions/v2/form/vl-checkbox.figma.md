# vl-checkbox

## Figma

Aanvinkvak om één of meer opties te kiezen. variant=switch is de aan/uit-schakelaar.

• Het label hoort bij het vakje. Een groep checkboxen krijgt een gezamenlijke naam via vl-fieldset.
• Een foutmelding is in code een aparte vl-form-message, geen deel van de checkbox. Maak ze specifiek: zeg wat de gebruiker moet doen.
• check en state zitten in een geneste instance, maar staan bovenaan in het paneel.
