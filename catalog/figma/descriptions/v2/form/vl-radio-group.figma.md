# vl-radio-group

## Figma

Groep keuzerondjes waarin de gebruiker één optie kiest.

• Selecteer bij voorkeur niets vooraf, zodat de gebruiker bewust kiest.
• De groep heeft een naam: het label bovenaan is in code het attribuut label.
• Een foutmelding is in code een aparte vl-form-message onder de groep. De annotatie uit Figma bestaat niet op de groep: gebruik een vl-form-message met variant annotation.
• Horizontaal of verticaal regelt in code de omliggende layout, niet de groep zelf.
