# vl-form-label

## Figma

Label boven een formulierveld. Elk veld heeft er een; een placeholder vervangt het niet.

• In code koppel je het met for aan de id van het veld, zodat een schermlezer het bij het veld voorleest.
• variant=light is in code het attribuut light.
• Staat er (verplicht) bij, zet dan in code required op het veld zelf.
