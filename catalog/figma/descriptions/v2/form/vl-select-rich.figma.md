# vl-select-rich

## Figma

Uitgebreide keuzelijst voor één optie of meerdere (multiselect).

• Zoals elk veld heeft het een zichtbaar label. Label, foutmelding en annotatie zijn in code aparte componenten naast het veld (vl-form-label, vl-form-message).
• open toont de uitgeklapte lijst; dat is geen attribuut in code.
• Na een variantwissel verdwijnen label en placeholder: vul ze opnieuw in.
