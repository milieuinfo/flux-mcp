# vl-datepicker

## Figma

Veld om een datum, een tijd of beide te kiezen. variant bepaalt het type: date, date-time of time.

• Zoals elk veld heeft het een zichtbaar label; een placeholder toont hooguit het verwachte formaat.
• Een periode van–tot bestaat in code (type range), maar niet als Figma-variant: beschrijf het in een annotatie.
• De Figma-property position toont de open kalender. Dat is niet het code-attribuut position.
