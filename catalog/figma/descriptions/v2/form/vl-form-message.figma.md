# vl-form-message

## Figma

Boodschap bij een formulierveld: een foutmelding (error), een bevestiging (success) of een altijd zichtbare toelichting (annotation).

• Maak foutmeldingen specifiek en geef de oplossing: "Vul een geldig e-mailadres in. Bijvoorbeeld: omgeving@vlaanderen.be", niet "Ongeldig".
• Toon één melding per validatie, de belangrijkste eerst.
• In code koppel je de melding met for aan het veld; ze verschijnt en verdwijnt dan mee met de validatie.
• Property=Label en Label light zijn in code een vl-form-label, geen form-message.
