# vl-accordion

## Figma

Blok dat informatie toont of verbergt via een toggle. Meerdere accordions onder elkaar zet je in code in een vl-accordion-list.

• De titel is de knop die opent en sluit: maak hem beschrijvend.
• In Figma staat de accordion altijd dicht. Moet hij open starten, dan is dat in code default-open.
• Het menu-icoon rechts is een voorbeeld: eigen acties komen in code in de slot menu.
