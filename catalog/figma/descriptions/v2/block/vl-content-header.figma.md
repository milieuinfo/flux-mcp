# vl-content-header

## Figma

Beeldband bovenaan informerende pagina's: achtergrondafbeelding met daarover de context (organisatie) en de titel (toepassingsnaam).

Code: <vl-content-header> met slots image, context-link en title-link. De component staat in code vast op --large --show-mobile --has-context.

size=L is de desktopweergave (>= 768px). size=S is de mobiele weergave: daar toont de code enkel de context; de titel is display:none.
