# vl-table-cell

## Figma

Eén cel in een vl-table. In code geen component, maar een gewone <td>, of <th> voor een kopcel.

• heading is een kopcel; of het een kolom- of rijkop is, volgt in code uit de plaats in de tabel.
• De statuskleuren (success, warning, error, disabled) zijn in code een klasse op de cel; zet de status ook in tekst.
• leading en trailing zijn cellen met een checkbox of knoppen; een rij heeft hooguit drie acties (icon row).
