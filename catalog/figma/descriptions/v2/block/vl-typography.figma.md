# vl-typography

## Figma

Container die de gewone HTML-elementen erin (koppen, paragrafen, lijsten, links) de Vlaamse opmaak geeft, zonder klassen per element. Bedoeld voor inhoud uit een wysiwyg-editor of CMS.

• Een pagina die je zelf opbouwt, maak je met de losse componenten: vl-title, vl-paragraph, vl-link.
