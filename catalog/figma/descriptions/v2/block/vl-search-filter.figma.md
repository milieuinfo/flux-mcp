# vl-search-filter

## Figma

Filterpaneel met zoekvelden, meestal naast een lijst of tabel (zie vl-rich-data).

• Het formulier zelf (secties, velden, knoppen) bouw je in de slot; elk veld heeft een zichtbaar label.
• variant=alt is in code het attribuut alt.
• Op mobiel toont de code het filter in een modal (mobile-modal); dat staat niet in Figma.
