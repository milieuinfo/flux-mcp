# vl-steps

## Figma

Verticale lijst van stappen die de gebruiker door een procedure leidt: een vl-steps met daarin vl-step-componenten.

• In code krijgt elke stap een kop (standaard h3). Past dat niet in de koppenstructuur van de pagina, dan zet de developer heading-level.
• De lijn en de tijdlijnweergaven stel je in Figma per stap in.
