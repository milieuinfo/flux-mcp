# vl-progress-bar

## Figma

Balk die procentuele voortgang toont. state toont success, error of indeterminate (voortgang onbekend).

• Toon in het design waarover de voortgang gaat. In code koppelt labelledby die tekst aan de balk, of geeft label hem een naam; een schermlezer heeft die nodig.
• De waarde (0-100) staat niet in Figma: die komt uit de data.
