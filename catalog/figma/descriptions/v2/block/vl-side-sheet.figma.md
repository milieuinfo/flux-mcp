# vl-side-sheet

## Figma

Paneel dat aan de linker- of rechterrand opengaat, terwijl de pagina ernaast zichtbaar en bruikbaar blijft. Moet de pagina afgeschermd worden, of gaat het om verwijderen, kies dan vl-modal (Storybook: Patronen / Overlays / Modal vs Side sheet).

• De inhoud is een vl-text als placeholder: swap die naar een .vl-stacked en vul die.
• variant combineert de kant (rechts is de default, left-*) met open, dicht en mobiel; mobiel volgt in code vanzelf uit de schermbreedte.
• show toggle button uit is in code hide-toggle-button.
