# vl-description-data

## Figma

Lijst van label-waardeparen die samen horen, zoals de metadata van een publicatie. In code een <dl>: een schermlezer leest elk paar als term en definitie.

• Enkel vl-description-data-item-elementen als directe kinderen: andere inhoud en ingepakte items worden in code genegeerd.
• variant=bordered is in code het attribuut bordered.
• Voor de meeste label-waardelijsten verdient vl-properties de voorkeur.
