# vl-pager

## Figma

Paginering onder een lijst of tabel: toont welke items je ziet en laat je bladeren.

• variant=simple toont enkel vorige en volgende; in code het attribuut pagination-disabled.
• De getallen zijn voorbeeldwaarden: totaal, huidige pagina en items per pagina komen in code uit de data.
• In code verbergt de pager zich niet bij één pagina; laat hem dan zelf weg.
