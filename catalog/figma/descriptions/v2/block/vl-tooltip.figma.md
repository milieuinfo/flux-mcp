# vl-tooltip

## Figma

Placement volgt de conventie van de code (floating-ui): top betekent dat de tooltip bóven de trigger staat, met het pijltje onderaan.

Content Default of Large toont enkel een korte of lange voorbeeldtekst.

In code hangt een tooltip altijd aan een focusbare trigger (for-attribuut, hover en focus): gebruik een knop, geen los icoon. Een tooltip heeft geen sluitknop.
