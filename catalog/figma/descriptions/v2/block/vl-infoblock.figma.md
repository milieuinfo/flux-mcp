# vl-infoblock

## Figma

Blok met icoon, titel en inhoud dat informatie van één soort bundelt, zoals contactgegevens.

• Het icoon volgt in code uit type: contact, publications, faq, news, timeline of question. In Figma bestaat enkel contact; een ander type vermeld je in een annotatie.
