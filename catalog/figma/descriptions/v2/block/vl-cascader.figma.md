# vl-cascader

## Figma

Drilldown door hiërarchische data: je kiest een item en krijgt de lijst van het niveau eronder. Bovenaan toont een breadcrumb waar je zit.

• Figma toont één niveau met vaste items; de hiërarchie zelf bouw je in code met geneste vl-cascader-item-elementen.
• breadcrumb uit is in code hide-breadcrumb.
• Plaats hem in code binnen <main>, <section>, <article> of <aside>, zodat de interne header geen banner-rol krijgt.
