# vl-autocomplete

## Figma

Invoerveld dat suggesties toont terwijl je typt. De suggesties komen in code uit een vaste lijst (static-list) of uit een API.

• Zet een zichtbaar label boven het veld (vl-form-label). De tekst in het veld wordt in code de placeholder: gebruik daar een voorbeeldwaarde, geen label.
• De geopende suggestielijst in Figma is een voorbeeld; in code toont het component zelf de gevonden items.
