# vl-loader

## Figma

Laadindicator met daaronder een tekst over wat er laadt, zoals "Pagina is aan het laden".

• Schermlezers lezen die tekst voor: zeg wat er laadt.
• variant light en single zijn in code de attributen light en single; single toont enkel de indicator, zonder tekst.
• In code staat de loader van bij het laden van de pagina in de DOM, verborgen en zonder tekst, en krijgt hij pas bij het laden zijn tekst. Anders leest een schermlezer hem niet betrouwbaar voor.
