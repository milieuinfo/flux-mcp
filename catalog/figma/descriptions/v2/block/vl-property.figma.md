# vl-property

## Figma

Eén regel in een vl-properties: een label en een waarde.

• variant=data slot vervangt de waarde door een placeholder: swap die naar de inhoud die je nodig hebt, bijvoorbeeld een vl-link.
• In code zijn het geen losse componenten, maar de tags vl-property en vl-property-data binnen vl-properties.
