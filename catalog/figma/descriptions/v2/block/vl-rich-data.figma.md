# vl-rich-data

## Figma

Container voor een gefilterde, gepagineerde dataweergave: zoekfilter links, datazone rechts (.vl-stacked), pager onderaan.

Twee booleans: open = filterpaneel uitgeklapt (uit = de mobiele weergave), pagination = pager tonen.

Gebruik dit component wanneer je zelf bepaalt wat er in de datazone komt. Gaat het om een tabel, neem dan vl-rich-data-table — in code is VlRichDataTable een subklasse van VlRichData, dus je kiest het een of het ander.
