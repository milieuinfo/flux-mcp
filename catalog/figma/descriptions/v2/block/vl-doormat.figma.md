# vl-doormat

## Figma

Grote tegel die als geheel naar een pagina binnen je website linkt, met titel, tekst en optioneel een afbeelding. Handig op een overzichtspagina.

• De titel zegt waar de tegel naartoe gaat.
• Een afbeelding is in code een url (image-src). Voegt ze informatie toe, dan hoort er een image-alt bij; beide staan niet in Figma.
• type bepaalt de alt-stijl en of er een afbeelding of graphic is; title only is een doormat zonder tekst.
