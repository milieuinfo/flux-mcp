# vl-table-row

## Figma

Eén rij in een vl-table. In code geen component, maar een gewone <tr>.

• heading is een rij in de <thead>. grid en zebra zijn stijlen van de hele tabel, geen instelling per rij.
• success, warning, error en disabled kleuren de rij (in code een klasse op de <tr>). Kleur alleen volstaat niet: zet de status ook in tekst.
• Een variantwissel wist de inhoud van de cellen.
