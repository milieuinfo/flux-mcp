# vl-side-navigation

## Figma

Inhoudstafel bij een lange pagina: vat de pagina samen en brengt je naar een sectie. Staat rechts van de content, binnen de content-block op een vl-grid; op mobiel erboven.

• In code is dit vl-side-navigation-next. Met heading-root-selector bouwt het de inhoudstafel zelf op uit de koppen van de pagina.
• Geef elke sectie een kop met een id: daar linkt de inhoudstafel naartoe.
• De titel is standaard "Op deze pagina".
