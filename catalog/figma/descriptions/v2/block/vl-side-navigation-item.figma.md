# vl-side-navigation-item

## Figma

Eén item in de inhoudstafel, met optioneel een subniveau.

• Het item linkt naar een sectie op de pagina of naar een andere pagina.
• De actieve toestand en het openklappen van een subniveau regelt de code zelf; die schrijf je niet uit.
