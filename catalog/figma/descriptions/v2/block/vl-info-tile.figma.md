# vl-info-tile

## Figma

Tegel voor informatieve en interactieve dashboards: titel, subtitel, inhoud en optioneel een icoon.

• icon-as-badge toont het icoon als badge. In code heeft de tegel daarvoor ook een icon nodig; zonder icoon verschijnt er niets.
• De highlight is in Figma een effect-stijl. In code zijn dat de attributen highlight en highlight-left, maar die verschijnen niet in het snippet: vermeld ze in een annotatie.
• Open en dicht (auto-open, clickable) bestaan enkel in code.
