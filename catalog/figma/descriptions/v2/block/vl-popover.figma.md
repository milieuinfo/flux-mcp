# vl-popover

## Figma

Klein venster dat bij een trigger opengaat, voor een context- of submenu. Het menu bouw je met vl-popover-action-list en vl-popover-action.

• In code hangt de popover met for aan de knop die hem opent. Die knop staat niet in de popover zelf: teken hem in het design ernaast.
• placement bepaalt de kant; bottom-center is de default. Is er te weinig plaats, dan kiest de code zelf een andere kant.
• arrow uit is in code hide-arrow.
