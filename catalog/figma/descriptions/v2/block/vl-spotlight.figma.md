# vl-spotlight

## Figma

Uitgelicht blok met titel, tekst en optioneel een afbeelding bovenaan, dat naar een pagina kan linken.

• Voegt de afbeelding informatie toe, dan hoort er in code een img-alt bij. De url's (img-src, link) staan niet in Figma.
• size bepaalt het formaat: L, S of XS.
