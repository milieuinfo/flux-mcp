# vl-properties

## Figma

Lijst van eigenschappen bij een object, zoals een dossier of een aanvraag: per regel een label en een waarde. Onze voorkeur voor label-waardelijsten.

• variant bepaalt de opbouw: default, column (twee kolommen, met Slot2) of collapsed (label boven waarde; in code stacked).
• padding-bottom uit is in code no-padding-bottom.
• Elke regel is een vl-property.
