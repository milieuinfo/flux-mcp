# vl-rich-data-table

## Figma

Datatabel met zoekfilter en paginatie — de tabelvariant van vl-rich-data (in code: VlRichDataTable extends VlRichData).

Dit component bevat een instance van vl-rich-data. De instellingen open en pagination staan op die geneste instance, niet op dit component zelf; selecteer ze een niveau dieper.

Bouw voor een overzichtspagina geen eigen kolomindeling met een losse vl-table ernaast.
