# vl-icon

## Figma

Icoon uit de Vlaamse icon library, [VL] Icons (team D). Swap het icoon via de property; de naam komt mee in het snippet.

• Een icoon is standaard decoratief en verborgen voor schermlezers. Draagt het betekenis zonder begeleidende tekst, dan krijgt het in code een label.
• Een icoon is nooit zelf klikbaar. Moet er iets gebeuren bij een klik, gebruik dan een vl-button ghost met icon-placement=only en een label als toegankelijke naam. Gaat de klik naar een andere pagina, gebruik dan een vl-link met icon en label. Het attribuut clickable van vl-icon is deprecated.
• Blijft icon leeg in het snippet, dan komt het gekozen icoon niet uit de library en bestaat het niet in code.
