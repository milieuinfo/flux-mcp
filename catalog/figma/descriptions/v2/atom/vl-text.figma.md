# vl-text

## Figma

Tekst met een andere opmaak: bold, underline, success, warning, error, annotation, small of italic.

• Puur opmaak: een boodschap bij een formulierveld is een vl-form-message, geen vl-text.
• In Figma is variant één as; in code zijn het losse attributen die je kan combineren.
• Kleur alleen draagt geen betekenis over: laat de tekst zelf zeggen dat het een fout of waarschuwing is.
