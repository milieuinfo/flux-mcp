# vl-link

## Figma

Link naar een andere pagina.

• Voert de link een actie uit op dezelfde pagina (een modal sluiten, naar de volgende stap, iets openklappen), dan krijgt hij in code button-as-link: technisch een knop, visueel een link. Typisch voorbeeld: "Annuleren" naast de knop "Opslaan". Het design toont dat verschil niet; leid het af uit de linktekst en de flow.
• icon=external opent in een nieuw tabblad. De component meldt dat zelf aan schermlezers: zet "(opent in een nieuw venster)" dus niet in de linktekst.
• Beschrijf waar de link naartoe gaat: "Bekijk je aanvragen", niet "Klik hier".
