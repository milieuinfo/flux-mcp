# vl-header

## Figma

Globale Vlaanderen-header; in code de Burgerprofiel-widget.

Kies size per breekpunt: L voor desktop (1440), S voor mobiel (375). Binnen een variant schaalt de header mee met de framebreedte. Tussen breekpunten wissel je zelf van variant — in code past de widget zich automatisch aan de viewport aan.
