# vl-group

## Figma

Layoutklasse die items naast elkaar zet, met een vaste tussenruimte.

Voor items onder elkaar is .vl-stacked de gewone keuze: daarmee bouw je een pagina of blok van boven naar onder op. .vl-group--column past bij een groep gelijkaardige items, zoals een reeks accordions.

• De groep bepaalt de ruimte tussen de items; de items zelf hebben geen marge.
• In code een CSS-klasse op een gewoon element, met de items als gewone kinderen.
