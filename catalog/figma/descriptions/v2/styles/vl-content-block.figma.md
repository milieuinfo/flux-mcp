# vl-content-block

## Figma

Layoutklasse die de inhoud groepeert op een vaste, gecentreerde breedte. Staat in een .vl-section; daarbinnen bouw je verder met .vl-stacked en .vl-grid.

• --full-width laat het blok de volledige breedte innemen, bijvoorbeeld voor een brede tabel of een kaart.
• In code een CSS-klasse op een gewoon element, geen component.
