# vl-group-input-group

## Figma

Zet een invoerveld en een knop of icoon tegen elkaar, zoals een zoekveld met zoekknop.

• variant toont welke inhoud aan welke kant staat. In code bepaalt de volgorde van de kinderen dat; de klasse is altijd vl-group--input-group.
• In code krijgen de kinderen zelf het attribuut input-group: <vl-input-field input-group> en <vl-button input-group>. Ook een icoon is een vl-button, met icon en label. Het snippet in Dev Mode toont dat attribuut niet.
