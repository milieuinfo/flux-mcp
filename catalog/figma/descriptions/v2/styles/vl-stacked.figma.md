# vl-stacked

## Figma

Layoutklasse die de verticale ruimte tussen de kinderen bepaalt: -small (15px), -medium (30px) of -large (60px). De gewone manier om een pagina van boven naar onder op te bouwen.

• De parent bepaalt de ruimte, niet het component: een component in een .vl-stacked heeft geen eigen marge. Gebruik titels dus met no-space-bottom.
• In code vl-stacked met vl-stacked-small, -medium of -large (één streepje).
