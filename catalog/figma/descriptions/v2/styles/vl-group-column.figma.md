# vl-group-column

## Figma

Layoutklasse die gelijkaardige items onder elkaar zet, met een vaste tussenruimte.

• Om een pagina van boven naar onder op te bouwen is .vl-stacked de gewone keuze; .vl-group--column past bij een groep gelijkaardige items.
• In code vl-group vl-group--column.
