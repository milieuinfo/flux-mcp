# vl-group-base

## Figma

Basiscomponent met alle modifiers van .vl-group op één as: kolom, uitlijning, scheidingslijnen, zonder tussenruimte, input group. .vl-group, .vl-group--column en de andere groepen zijn er varianten van.

• Nooit los gebruiken: de base zit altijd in .vl-group of een andere groep, en zijn variant bepaalt de modifier van die groep.
• In code één element met de klasse vl-group en de modifier-klassen, zoals vl-group--column of vl-group--justify-end; nooit een groep in een groep.
