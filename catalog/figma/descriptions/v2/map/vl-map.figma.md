# vl-map

## Figma

Kaart met lagen en acties. In Figma zet je layer-switcher, search, legend en tools aan of uit; in code zijn dat aparte kind-componenten (vl-map-layer-switcher, vl-map-search, vl-map-legend, vl-map-action-controls).

• De zoomknoppen staan in code altijd op de kaart.
• Een kaart heeft in code een basislaag nodig, zoals vl-map-baselayer-grb-gray; die staat niet in Figma.

Bekijk de patronen voor een mobile voorbeeld en een uitwerking met side-sheet.
