# Map WMTS Layer

## Doel

Gebruik de `map-wmts-layer` component om een WMTS kaartlaag af te beelden.

Deze component erft over van de `VlMapLayer` klasse.

## Voorbeeld

```js
import { VlMapWmtsLayer } from '@domg-wc/map';
```

```html
<vl-map-wmts-layer></vl-map-wmts-layer>
```
