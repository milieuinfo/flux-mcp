# Document

## Doel

Gebruik de `document` component om een link naar een bestand toe te voegen dat de gebruiker in de browser kan bekijken
of downloaden.

## Voorbeeld

```js
import { VlDocumentComponent } from '@domg-wc/components/block';
```

```html
<vl-document></vl-document>
```

> Story: [vl-document - default](/?path=/story/components-block-document--document-default)
