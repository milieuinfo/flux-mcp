# Cookie Consent

## Doel

De cookie consent kan gebruikt worden om de gebruiker te informeren over al de cookies die gebruikt worden.
Daarnaast kunnen er mits toestemming van de gebruiker analytics worden toegepast.

## Voorbeeld

```js
import { VlCookieConsent } from '@domg-wc/components/compliance';
```

```html
<vl-cookie-consent></vl-cookie-consent>
```

> Story: [vl-cookie-consent - default](/?path=/story/components-compliance-cookie-consent--cookie-consent-default)

## Configuratie

> API: vl-cookie-consent, vl-cookie-consent-opt-in
