# Map Baselayer GRB Gray

## Doel

Gebruik de `map-baselayer-grb-gray` component om een basis GRB kaartlaag met grijstinten af te beelden.

Deze component erft over van de [map-baselayer](/?path=/docs/map-baselayer--map-baselayer-default) component.

## Voorbeeld

```js
import { VlMapBaseLayerGRBGray } from '@domg-wc/map';
```

```html
<vl-map-baselayer-grb-gray></vl-map-baselayer-grb-gray>
```

> Story: [vl-map-baselayer-grb-gray - default](/?path=/story/map-baselayer-baselayer-grb-gray--map-baselayer-grb-gray-default)

## Configuratie

Deze component heeft geen configuratie.
