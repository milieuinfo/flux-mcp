# Alert

## Doel

Gebruik de `alert` component om de gebruiker op de hoogte te houden van belangrijke informatie.

## Voorbeeld

```js
import { VlAlert } from '@domg-wc/components/block';
```

```html
<vl-alert></vl-alert>
```
