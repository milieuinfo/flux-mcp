# Map WMS Style

Gebruik de `map-wms-style` component om een WMS kaartlaag server side te stijlen.

## Voorbeeld

```js
import { VlMapWmsStyle } from '@domg-wc/map';
```

```html
<vl-map-wms-style></vl-map-wms-style>
```
