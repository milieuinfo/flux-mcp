# Search Result

Gebruik de `search-result` component om een zoekresultaat weer te geven.

Volgende sub-componenten zijn beschikbaar om het zoekresultaat op te bouwen:

- VlSearchResultProperties `[vl-search-result-properties]`
- VlSearchResultText `[vl-search-result-text]`
- VlSearchResultTitle `[vl-search-result-title]`

## Voorbeeld

```js
import { VlSearchResultComponent } from '@domg-wc/components/block';
```

```html
<vl-search-result></vl-search-result>
```

> Story: [vl-search-result - default](/?path=/story/components-block-search-result--search-result-default)

## Configuratie

> API: vl-search-result, vl-search-result-properties, vl-search-result-text, vl-search-result-title
