# Map Baselayer GRB Ortho

Gebruik de `map-baselayer-grb-ortho` component om een basis GRB ortho kaartlaag af te beelden.

Deze component erft over van de [map-baselayer](/?path=/docs/map-baselayer--map-baselayer-default) component.

## Voorbeeld

```js
import { VlMapBaseLayerGRBOrtho } from '@domg-wc/map';
```

```html
<vl-map-baselayer-grb-ortho></vl-map-baselayer-grb-ortho>
```
