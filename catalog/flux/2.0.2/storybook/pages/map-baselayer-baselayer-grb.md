# Map Baselayer GRB

Gebruik het `map-baselayer-grb` component om een basis GRB kaartlaag af te beelden.

Dit component erft over van het [map-baselayer](/?path=/docs/map-baselayer--map-baselayer-default) component.

## Voorbeeld

```js
import { VlMapBaseLayerGRB } from '@domg-wc/map';
```

```html
<vl-map-baselayer-grb></vl-map-baselayer-grb>
```
