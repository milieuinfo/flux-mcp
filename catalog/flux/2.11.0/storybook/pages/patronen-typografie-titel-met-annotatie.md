# Titel - met Annotatie

Een annotatie kan naast een titel geplaatst worden om extra context te bieden.

## Voorbeeld

> Story: [titel - met annotatie](/?path=/story/patronen-typografie-titel-met-annotatie--titel-met-annotatie)

**Code**

```html
<div class="vl-group vl-group--baseline">
            <vl-title type="h2" no-space-bottom>Mijn sectie</vl-title>
            <vl-text annotation>Optioneel</vl-text>
        </div>
```
