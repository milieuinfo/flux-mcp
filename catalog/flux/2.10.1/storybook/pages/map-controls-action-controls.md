# Map Action Controls

## Doel

Gebruik de `map-action-controls` component als wrapper rond
[map-action-control](/?path=/docs/map-controls-action-control--map-action-control-default) componenten.

De `map-action-controls` zorgt ervoor dat de map-acties in de rechterbovenhoek van de `map` afgebeeld worden.

Verder zorgt deze ervoor dat er altijd maar 1 actieve `map-action-control` is.

## Voorbeeld

```js
import { VlMapActionControls } from '@domg-wc/map';
```

```html
<vl-map-action-controls></vl-map-action-controls>
```

> Story: [vl-map-action-controls - default](/?path=/story/map-controls-action-controls--map-action-controls-default)

## Configuratie

Deze component heeft geen configuratie.
