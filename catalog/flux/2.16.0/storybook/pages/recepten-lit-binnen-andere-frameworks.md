# Lit binnen andere frameworks

Ondersteuning voor de grootste frameworks vind je hieronder.

|  |  |
| --- | --- |
| Versie | Ondersteuning |
| Angular 16.2.10 | volledig ondersteund |
| Vue 3.2.38 | volledig ondersteund |
| React &lt;= 18 | weinig ondersteuning maar gebruik van &#64;lit/react maakt het makkelijker |
| React 19 | volledig ondersteund |

Voor een vollediger overzicht kan je terecht op
[custom-elements-everywhere.com](https://custom-elements-everywhere.com/), een website waar de status van
[custom elements](https://developer.mozilla.org/en-US/docs/Web/API/Web_components#custom_elements_2) en framework interoperability testen wordt bijgehouden.
Dit komt typisch overeen met de compatibiliteit van Lit-elementen.
