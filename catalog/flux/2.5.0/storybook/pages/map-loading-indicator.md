# Map Loading Indicator

Gebruik de `map-loading-indicator` component om op te vangen wanneer de [vl-map](/?path=/docs/map-map--map-default) aan het
laden is.

Toont een 'loading' bar bovenaan de map.

## Voorbeeld

```js
import { VlMapLoadingIndicator } from '@domg-wc/map';
```

```html
<vl-map-loading-indicator></vl-map-loading-indicator>
```
