# Digitaal Vlaanderen Footer

Injecteert de footer widget (v5) van Digitaal Vlaanderen.
Default wordt de footer geïnjecteerd in het native `<body>` element.

## Voorbeeld

```js
import { VlFooterNext } from '@domg-wc/components/compliance';
```

```html
<vl-footer-next></vl-footer-next>
```

> Story: [vl-footer-next - default](/?path=/story/components-compliance-footer-next--footer-default)

## Configuratie

> API: geen element in de web-types. Zie de argTypes in [Storybook](/?path=/story/components-compliance-footer-next--footer-default).
